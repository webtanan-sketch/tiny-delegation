# Tiny Delegation — تفویض کار

ماژول سبک و دو‌زبانه TinyManager برای ثبت و پیگیری کارهای سپرده‌شده.

اصل UX: **مدیر فقط کار و شخص را بگوید**؛ پروژه، موعد، اولویت و توضیح اختیاری‌اند.

## فرمان نمونه Tiny AI

`پیگیری قرارداد را به علی بسپار`

جریان پیشنهادی در TinyManager:

تشخیص تفویض → استخراج کار و شخص → پیش‌نمایش → تأیید → Shared People → ثبت Delegation

## قابلیت‌های Alpha

- Standalone App
- TinyManager Module package
- ثبت سریع با دو ورودی
- وضعیت باز / انجام‌شده / لغوشده
- ثبت آخرین پیگیری
- اتصال با `personId` و `projectId`
- Local-first storage contract
- TypeScript declarations
- تست Domain و GitHub Actions CI
