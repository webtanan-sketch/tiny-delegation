# Tiny Delegation

A lightweight bilingual TinyManager module for delegated work.

The manager only needs to provide **task + person**. Project, deadline, priority and notes remain optional.

Example Tiny AI command:

`Delegate contract follow-up to Ali`

## Alpha capabilities

- Standalone app
- TinyManager module package
- Two-field quick capture
- Open / done / cancelled status
- Follow-up timestamp
- `personId` and `projectId` links
- Local-first storage contract
- TypeScript declarations
- Domain tests and GitHub Actions CI

Version: `0.1.0-alpha.1`
